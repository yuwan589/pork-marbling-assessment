About the System

This system is Pork Marbling Intelligent Assessment System. Based on image processing algorithms, it automatically analyzes fat distribution in muscle cross-section images, outputs Fat Ratio and Marbling Grade, supports single and batch modes, and exports results to Excel.

Form Field Guide

After entering the main page, the first module is "Animal Measurement Info". Please fill in the following information before measurement. This data will be exported to Excel along with the results.

Location Slaughterhouse or lab name, e.g. "ABC Abattoir"
Operator Name of the person performing this measurement
Breed Pig breed, e.g. "Duroc", "Landrace", etc.
Gender Boar / Sow / Barrow, select from dropdown
Date System auto-fills today's date; can be manually edited
Tip
All fields are optional and do not affect image analysis, but completing them is recommended for traceability.

Single Image

In Single Image mode, the system provides three independent upload slots (Image 1/2/3). Each image can be analyzed individually, or click "Analyze All" for batch processing.

Best for: measuring a small number of samples, reviewing each result individually.

Batch Mode

In Batch Mode, you can select or drag multiple images at once. After clicking "Start Batch Analysis", the system processes all images sequentially and displays results in the summary table below.

Best for: large-scale sample measurement, quickly getting summary data and exporting to Excel.

Mode Comparison
Single mode: up to 3 images, with Original vs Marked Image comparison.
Batch mode: unlimited images, results summarized in table, suitable for large-scale data collection.

Single Image Operation Steps

1
Fill in Measurement Info
Fill in Location, Operator, Breed, Gender and Date in the top info form.
2
Upload Images
Click the upload area of an image slot, or drag image files into the dashed box. JPG/PNG supported. Preview after upload; click "×" at top-right to remove.
3
Click Analyze
Click the "Analyze" button below an image for single analysis; or click the "Analyze All" button to process all uploaded images at once. During analysis, the button shows "Analyzing" with a rotating loader.
4
View Results
After analysis, view Fat Ratio, Marbling Grade and Fat Area for each image in the results section below, along with Original vs Marked Image comparison.
5
Export Data
Click the "Export Measurement Data" button to export measurement info and analysis results as an Excel file (.xlsx). The filename includes the date.

Batch Mode Operation Steps

1
Switch to Batch Mode
Click the "Batch Mode" button at the top of the upload module to switch modes.
2
Select or Drag Images
Click the upload area or drag multiple images into the upload box. You can select multiple files at once. After uploading, thumbnails of all images will be displayed below.
3
Start Batch Analysis
Click the "Start Batch Analysis" button. The system will process each image sequentially. The thumbnail top-left shows processing status (orange=processing, green=complete).
4
View Summary & Export
After analysis completes, the summary table below shows results for all images. Click "Export Results" to export batch results to Excel.
Friendly Tip
Image analysis runs entirely locally in the browser. Images are not uploaded to any server, so please use with confidence. Analyzing large images may take several seconds, please wait patiently.

Marbling Grade Standard

The system divides Marbling Grade according to the detected Fat Area ratio in the muscle cross-section image, based on the following standards:

GradeFat Area Ratio RangeQuality Description
Grade 1≤ 0.275%No marbling, extremely low fat
Grade 20.275% ~ 2.284%Trace marbling
Grade 32.284% ~ 5.902%Slight marbling
Grade 45.902% ~ 8.703%Moderate marbling
Grade 58.703% ~ 12.464%Medium marbling
Grade 612.464% ~ 18.045%Modestly abundant marbling
Grade 718.045% ~ 23.508%Abundant marbling
Grade 823.508% ~ 28.232%Highly abundant marbling
Grade 928.232% ~ 33.355%Extremely Abundant marbling
Grade 10+> 33.355%Super Abundant marbling

Marked Image Guide

In the result images, green highlighted areas are fat (marbling) distribution identified by the system; the background is preprocessed muscle tissue.

Analysis Principle
The system uses OTSU threshold segmentation, Lab color space filtering, and connected component analysis to automatically extract valid muscle regions, identify fat particles based on block-normalized brightness distribution, and finally calculate the Fat Area ratio and determine the Grade according to the rating table.
