PorkMS: Help & Guide

About PorkMS

PorkMS: Pork Marbling Measurement System is a browser-based image analysis tool. Based on image processing algorithms, it automatically analyzes fat distribution in muscle cross-section images, outputs Fat Ratio and Marbling Grade. No login or registration is required — open the page and start measuring immediately.

Key Features

No Login Open the page and start using immediately, no account needed
Single Image Mode Import one image, measure one, save one — simple and efficient
History Records All results automatically saved in the results panel, sorted by time
Export CSV Export all historical measurement data as a CSV file
Trial Quota 100 measurements per trial. Contact the developer for extended access.
Local Processing All image analysis runs entirely in your browser, no data uploaded
Privacy Notice
PorkMS: Pork Marbling Measurement System runs entirely locally in your browser. No images or data are sent to any server. Your data is completely private.

Form Field Guide

At the top of the page is the "Animal Measurement Info" panel. Filling in this information is optional but recommended for record-keeping. All entered data will be included in the exported CSV file.

Location Slaughterhouse or lab name, e.g. "ABC Abattoir"
Operator Name of the person performing this measurement
Breed Pig breed, e.g. "Duroc", "Landrace", etc.
Gender Boar / Sow / Barrow, select from dropdown
Date System auto-fills today's date; can be manually edited
Tip
All fields are optional and do not affect image analysis accuracy. Completing them is recommended for better data traceability when exporting results.

Single Image Measurement Steps

1
Fill in Measurement Info (Optional)
Optionally fill in Location, Operator, Breed, Gender and Date in the top info form. This helps with record management.
2
Import an Image
In the "Image Upload & Measurement" panel, click the upload area or drag an image file into the dashed box. JPG and PNG formats are supported. A preview will appear after upload. Click "×" at the top-right to remove the image.
3
Start Measurement
Click the "Start Measurement" button below the image. The button shows "Analyzing" with a spinner during processing. Each successful measurement uses 1 trial quota.
4
View Results
After analysis, the result is automatically added to the "Measurement History Results" panel at the bottom of the page. Each record shows: measurement time, image thumbnails (original & marked), Fat Ratio and Marbling Grade. All results are sorted by time and can be scrolled.
5
Export or Clear Results
Click "Export All as CSV" in the results panel header to download all historical records as a CSV file. Click "Clear All Results" to remove all records from the current session.

Standard Test Images

The "Standard Test Images" gallery provides 6 reference images (Grade 1–6). Click "Analyze" under any test image to quickly analyze it and add the result to the history panel. This feature is useful for verifying the system's measurement accuracy.

Performance Note
Image analysis runs entirely in your browser. No data is uploaded to any server. Analyzing large images may take a few seconds — please wait patiently.

Trial Measurement Quota

PorkMS: Pork Marbling Measurement System provides 100 free trial measurements per session. The remaining quota is shown in the banner at the top of the page.

Initial Quota 100 times
Counting Rule Only successful measurements are counted. Importing an image without clicking "Start Measurement" does not count.
Quota Reset Quota resets when the page is refreshed or reopened
Exhausted When quota reaches 0, the "Start Measurement" button is disabled. Contact the developer to continue.
Contact Developer
If the trial quota is exhausted or you need extended access, please contact the system developer for assistance.

Marbling Grade Standard

The system divides Marbling Grade according to the detected fat ratio in the muscle cross-section image, based on the following standards:

Grade 1≤ 0.275%No marbling, extremely low fat

Marked Image Guide

In the result thumbnails, green highlighted areas are fat (marbling) distribution identified by the system; the background is preprocessed muscle tissue.

Analysis Principle
The system uses OTSU threshold segmentation, Lab color space filtering, and connected component analysis to automatically extract valid muscle regions, identify fat particles based on block-normalized brightness distribution, and finally calculate the fat ratio and determine the Grade according to the rating table.
