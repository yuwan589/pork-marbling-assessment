# Pork Marbling Assessment System

猪肉大理石花纹评估系统 - 在线演示

## 在线访问

**GitHub Pages**: https://yuwan589.github.io/pork-marbling-assessment/

## 本地运行

1. 克隆仓库
2. 直接在浏览器中打开 `index.html`

注意：本项目使用本地图片相对路径引用，不支持 `file://` 协议直接双击打开。
请使用本地服务器（如 `python -m http.server 8000`）或部署到GitHub Pages。

## 功能特性

- 登录认证系统
- 6张标准测试图展示
- 一键分析所有测试图
- 单张图片上传分析
- Excel批量导出功能
